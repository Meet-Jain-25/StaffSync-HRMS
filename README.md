# StaffSync – Modern Human Resource Management Solution

StaffSync is a web-based Human Resource Management System (HRMS)
designed to simplify employee management and streamline everyday HR
operations through a centralized platform.

## Project Overview

The project follows the MERN stack:

- MongoDB – Database
- Express.js – Backend framework
- React.js – Frontend library
- Node.js – Runtime environment

## Key Features

- Role-based dashboards for HR, Managers, and Employees
- Employee information management
- Leave application and approval
- Attendance check-in, check-out, and history
- Announcements and organizational updates
- Training program management
- Secure authentication and authorization
